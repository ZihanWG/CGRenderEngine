05 · responsibility boundary

Draw Call 是分界线，不是终点

CPU 负责准备状态与命令；glDrawElementsInstanced 把“按当前状态绘制这些索引、这些实例”的工作交给驱动 / GPU。

CPU · Engine code

1RenderSubmission 排序并构造 InstancedDrawBatch
2ScenePass 上传 Frame / Lighting / Object UBO
3MaterialBinder 绑定 Material UBO 与纹理 1–5
4设置 Blend / Cull，绑定 VAO

    为什么 Decode 可异步？

    文件解析、accessor 转换和 CPU 数组构造不需要 OpenGL Context。

    为什么 Finalize 回主线程？

    Texture2D::Allocate、Mesh 上传会调用 OpenGL。

    Reference 如何并行？

    CPU RayTracer 通过 JobSystem 运行，完成后主线程上传参考纹理。

    “看懂”与“证明运行”不是一回事

    按证据层级验证。源码能证明契约存在，测试能证明部分行为，只有窗口运行与捕获能证明 GPU 实际执行和视觉结果。
